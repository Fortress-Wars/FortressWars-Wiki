### Parkour Enhancements

- Added difficulty for each map.
- Added support for out-of-bounds configurations.
- Updated the time tracking to be more accurate.

### Pause Command Enhancements

- Added a "Paused" text overlay,
- Added a countdown when the game is being unpaused.
- /game pause now pauses:
  - Damage and healing processing.
  - Ability durations, cooldown timers, and refresh/regeneration timers.
  - Ability/background scheduled tasks (via PauseableTask/refactored base pause handling).
  - Potion effects and status effect ticking.
  - Respawn wave progression.
  - Assist tags, stun timers, hack-related tasks, and inventory pause state handling.
- Added discord hook to broadcast when a game pauses or unpauses.

### Kit Changes

Priest

- Rename "Sun Power" to "Grace"
- Rename the "Release" spell to the "Absolution" ability.

### Other Changes

- Update wording for spectating when there is no game currently running.
- Renamed some achievements.
- King of the Hill
  - Minions can now trigger overtime.
  - Updated the overtime decay duration change in 3 stages.
    - Elapsed Duration: 0-19 seconds -> 5 second decay.
    - Elapsed Duration: 20-29 seconds -> 3 second decay.
    - Elapsed Duration: 30+ seconds -> 1.5 second decay.
  - Beacon capture progress timer now resets when capturing the beacon.
  - Game stays in overtime if capturing at 99%.
- Removed commands to set the player rank and custom title as they are now managed by the api.
- Standardized the format of all commands.
- Updated the map and gamerule voting menus.
- The kit menu now updates when teammates select a kit.

### Admin Command Changes

- Removed functionality to control some player data through commands in game as it is now done through the API.
  - Unlock or lock `all` kits at the same time.
  - Unlock kit using credits.
  - Set the rank of a player.
  - Set the customTitle of a player.
  - Add a subscription

### Bug Fixes

- Fixed issue where the Imbue spell would not disable correctly.
- Fixed issue where the Smite death animation causes the server to crash.
- Fixed issue where kit Demon's healing is duplicated if standing parallel with another player.
- Fixed issue where the Homing Hemoglobin projectile could get stuck on an ally.
